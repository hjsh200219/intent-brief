# 하네스 성숙도

## 차원과 가중치

| 차원 | 원칙 | 가중 |
|---|---|---|
| A. 문서·탐색 | P1·P2·P5·P12 | 0.3 |
| B. 강제·일관성 | P3·P4·P10 | 0.3 |
| C. 구조·지식 | P6·P9·P11 | 0.2 |
| D. 운영·유지 | P7·P8 | 0.2 |

종합 = (A×0.3 + B×0.3 + C×0.2 + D×0.2) × 10 (차원 점수는 소속 원칙 평균). 60 이상 통과 · 40~59 경고 · 39 이하 실패.

## 등급

| 등급 | 정의 |
|---|---|
| L1 | 진입점이 없거나 낡았다 |
| L2 | 진입점과 검증 명령이 있으나 강제가 수동이다 |
| L3 | 레이어·의존·문서 드리프트를 도구가 실패시킨다 |
| L4 | 검사 결과가 추세로 기록되고 회귀가 자동으로 드러난다 |
| L5 | 하네스가 스스로 불필요한 검사를 걷어 내며 GC 메타 검증이 돈다 |

기준선: 아직 없음(첫 `/sh:harness-gc` 결과를 `gc-history.md` 에 기록).
