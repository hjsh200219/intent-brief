# 빅케이스 자격증명 등록

**비밀번호를 채팅으로 묻지 않는다. 사용자가 채팅에 비밀번호를 붙여 넣으면 쓰지 말고, 노출됐으니 빅케이스에서 비밀번호를 바꾸라고 안내한다.**

사전 점검 없이 아래 명령 하나를 바로 실행한다. 인자로 이메일을 받았으면 `--email "$ARGUMENTS"` 를 붙이고, 없으면 붙이지 않는다(필요하면 명령이 입력 창으로 묻는다).

실행 직전에 한 줄만 말한다:
> 화면에 「BigCase」 입력 창이 뜨면 이메일·비밀번호를 넣어 주세요. 비밀번호는 이 대화에 남지 않고 OS 키체인에만 저장됩니다. (이미 등록돼 있으면 창 없이 끝납니다)

```bash
uv run "${CLAUDE_PLUGIN_ROOT}/skills/case-search/scripts/bigcase.py" setup
```

Bash 도구 `timeout` 은 **600000**(10분)으로 준다 — 사람이 입력하는 동안 기본 2분에 끊기면 안 된다.
`uv` 가 없다는 오류면 설치를 안내한다(대신 깔지 않는다): macOS `curl -LsSf https://astral.sh/uv/install.sh | sh` · Windows `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`. 처음 한 번은 의존성을 받느라 수십 초 걸릴 수 있다.

명령이 하는 일: 이미 등록돼 있으면 창 없이 토큰만 확인한다. 아니면 이메일(필요할 때)·비밀번호 창 → 로그인 1회로 확인 → **맞을 때만** 키체인에 저장.
**실패해도 같은 명령을 자동으로 다시 돌리지 않는다.** 결과를 알리고 다시 할지 묻는다.

결과 읽기:
- `✓ 등록 완료` / `✓ 이미 등록돼 있습니다` → 한 줄로 알리고 끝.
- `✗ 저장하지 않았습니다 — 로그인 실패 HTTP 4xx …` → 이메일 또는 비밀번호가 틀렸다.
- `✗ 저장하지 않았습니다 — 로그인 미완료 signInStatus=…` → 비밀번호는 맞지만 빅케이스·로이어즈원 계정 통합이 남았다. 브라우저에서 bigcase.ai 로그인 후 안내대로 통합하라고 알린다.
- `✗ 입력을 취소했습니다` → 그대로 끝낸다.
- `✗ 입력 창을 띄울 수 없습니다`, 또는 사용자가 원격 접속이라 창을 볼 수 없다 → 사용자가 **자기 터미널에서** 실행하게 안내한다: `uv run "${CLAUDE_PLUGIN_ROOT}/skills/case-search/scripts/bigcase.py" setup` — 경로는 실제 값으로 풀어서 보여 준다.
- `✗ 이 컴퓨터에서 쓸 수 있는 키체인이 없습니다` → 환경변수 `BIGCASE_ID`/`BIGCASE_PW` 를 안내한다.

다른 계정으로 바꾸거나 비밀번호를 새로 넣으려면 `setup --force`, 지우려면 `forget`.
