# litigation-calc — 법정기간·소송비용 계산

날짜·금액은 모델이 셈하지 않고 스크립트로 계산한다. 스크립트는 표준 라이브러리만 쓴다(Python 3.9 이상).
`$C` = `${CLAUDE_PLUGIN_ROOT}/skills/litigation-calc/scripts`. Python 은 `python3` → `python` → `py -3` 순서로 찾는다.

## 1. 기간 만료일

```
python3 "$C/deadline.py" presets                                    # 기간 종류·근거 조문 목록
python3 "$C/deadline.py" calc 2026-10-17 --preset 민사-항소          # 판결서 송달일 기준
python3 "$C/deadline.py" calc 2026-10-15 --n 3 --unit 월             # 직접 지정(일·주·월·연)
python3 "$C/deadline.py" calc 2026-10-25 --n 7 --unit 연 --regime 형사시효
```

- 입력은 기산 기준일(송달일·고지일·선고일)이다. 그날은 넣지 않고 다음 날부터 센다(초일 불산입). 오전 영시부터 시작하는 기간이면 `--from-midnight`(민법 제157조 단서).
- `--regime`: `민사`(민법, 행정소송도 이것) · `형사`(형사소송법 제66조) · `형사시효`(시효·구속기간 — 초일 산입, 말일 연장 없음).
- 말일이 토요일·일요일·공휴일이면 다음 날로 넘어간다(연휴는 이어서). 공휴일은 `references/holidays.json`(한국천문연구원 특일정보 2024–2028)이다. 임시공휴일·표 밖 연도는 `--holiday YYYY-MM-DD` 로 더한다. 결과 `warnings` 에 「공휴일 표 범위 밖」이 있으면 변호사에게 그대로 알린다.
- 결과를 보여 줄 때: 만료일(요일), 근거 조문, 기산 기준(`from`), 넘어간 날과 이유(`shifted`), 불변기간 여부(`invariable` — 형사 상소기간은 `null`), `note`, D-day.
- 송달일·고지일 자체가 확실하지 않으면 계산 결과 옆에 `[확인 필요: 송달일]` 을 붙인다. 공시송달·외국 송달·발신주의 같은 특수한 송달 효력 발생일은 이 계산기가 정하지 않는다.

## 2. 소송비용

```
python3 "$C/costs.py" stamp 30000000                       # 소장 인지액
python3 "$C/costs.py" stamp 30000000 --doc 항소장 --electronic
python3 "$C/costs.py" service 민사단독 --parties 2 [--unit 5500]
python3 "$C/costs.py" interest 10000000 --segment 2026-01-01:2026-03-15:민사 --segment 2026-03-16:2026-04-15:소촉법
```

- 인지액: 소송목적의 값(소가)을 넣는다. 소가 산정 자체(민사소송 등 인지규칙)는 변호사가 정한다. 서류 `소장·반소장·항소장·상고장·화해신청서·지급명령`, 전자소송이면 `--electronic`(10분의 9).
- 송달료: 「송달료규칙의 시행에 따른 업무처리요령」 별표 1 회분 × 당사자 수. 1회분 금액은 예규에 없으므로 변호사가 확인한 단가를 `--unit` 으로 받는다. 없으면 회분만 알리고 「단가 확인 필요」로 둔다.
- 지연손해금: 구간마다 `시작:끝:이율`(이율 `민사` 5% · `상사` 6% · `소촉법` 12% 또는 `0.15` 같은 약정 이율). 일수는 양 끝 포함, 연 365일, 원 미만 버림.

## 3. 기한·기일 D-day 점검

```
python3 "$C/dday.py" roots add "<사건 폴더들이 모인 폴더>"   # 한 번 등록(바로 아래 폴더의 사건메모.md 를 본다)
python3 "$C/dday.py" scan [--days 30]                        # 다가오는 기한·기일 목록(JSON)
python3 "$C/dday.py" roots list | roots remove "<폴더>"
```

- 사건메모 「주요 일정」 절의 날짜 줄을 모은다. 지운 줄(`~~…~~`)·`[x]`·「완료」 줄은 뺀다. intent-brief 로 작업한 사건은 등록하지 않아도 들어간다.
- 항소·상고·항고·이의·추후보완·재심·제소·시효·제척·불변이 들어간 줄은 불변기간·시효로 강조한다. 이런 줄의 날짜가 맞는지 의심되면 1의 `deadline.py` 로 다시 계산해 보여 준다.
- 플러그인을 설치하면 세션을 시작·재개할 때 14일 안의 것을 자동으로 알린다(`hooks/hooks.json`). 다가오는 것이 없으면 아무것도 출력하지 않는다. 등록한 폴더를 `roots remove` 하면 그 폴더의 사건은 빠진다(intent-brief 작업 사건은 `state.py purge` 로 작업 폴더를 지우면 빠진다).

## 4. 오류

`"ok": false` 면 `message` 를 그대로 알리고 입력을 다시 받는다. 계산 결과는 조문 기준의 산술이다 — 특수 송달·기간 연장 결정·소가 산정은 변호사가 판단한다.
