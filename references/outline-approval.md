# 구성안 → 승인 → 작성

법률 문서 스킬(내용증명·고소장·형사합의서·사실확인서·형사절차 시뮬레이터·양형 예측)이 본문을 쓰기 전에 거치는 공통 절차다. 긴 문서를 다 쓴 뒤에 방향이 틀린 것을 알면 다시 쓰는 비용이 크므로, 뼈대를 먼저 맞춘다.

## 구성안 다섯 요소

1. **목표** — 이 문서로 얻으려는 것 한 문장(예: 「2주 안에 대여금 3천만 원 반환을 받거나, 받지 못하면 지급명령 신청 근거를 남긴다」).
2. **쟁점 3–6개** — 쟁점마다 뒷받침하는 증거를 붙인다(자료 이름·증거 번호). 증거가 없는 쟁점은 「증거 없음」으로 표시한다.
3. **목차** — 스킬마다 정한 문서 구조를 이 사건에 맞춰 채운 순서.
4. **확인 필요** — 자료에 없어서 본문에 `[확인 필요: …]` 로 남길 사실. 지어내지 않는다.
5. **인용 예정** — 쓸 조문·판례. 아직 조회하지 않았으면 「조회 예정」, 조회했으면 「법제처 확인」을 붙인다(조회는 [law-lookup.md](law-lookup.md)).

## 진행

- 구성안은 일반 텍스트 한 번으로 보여 준다(선택 창 도구를 쓰지 않는다). 짧게 — 화면 한 쪽 안.
- 「승인」·「진행」·「좋아」 같은 답이면 그 구성안대로 본문을 쓴다.
- 고칠 점을 말하면 구성안만 고쳐 다시 보여 준다. 본문은 승인 뒤에 쓴다.
- 변호사가 처음부터 「바로 작성」이라고 하거나 같은 사건의 같은 문서를 다시 쓰는 경우에는 구성안을 건너뛰고 쓴다.
- 승인한 구성안과 본문이 달라졌으면(쓰다 보니 쟁점이 늘었다 등) 본문을 보여 줄 때 무엇이 달라졌는지 한 줄로 알린다.

## 보기

```
구성안 — 내용증명(대여금 반환 청구)
목표: 2주 안에 3,000만 원 반환. 불응하면 지급명령 신청의 근거로 쓴다.
쟁점: ① 대여 사실 — 계좌이체 내역(2025. 3. 2.) ② 변제기 도래 — 차용증 「2026. 3. 1.까지」 ③ 지연손해금 — 차용증 이율 약정 없음 → 민법 연 5%
목차: 제목 · 수신인/발신인 · 사실관계 · 요구사항(금액·계좌) · 기한(수령 후 14일) · 불이행 시 조치 · 첨부(이체 내역)
확인 필요: 수신인 현재 주소
인용 예정: 민법 제379조(법정이율) — 조회 예정
승인하시면 이대로 작성합니다.
```
